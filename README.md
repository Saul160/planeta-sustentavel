Descrição

O Planeta Sustentavel é um site que apresenta a importância da sustentabilidade e da preservação do meio ambiente.

O objetivo é mostrar como pequenas atitudes podem ajudar a cuidar do nosso planeta.

Páginas
index.html: apresentação geral do projeto.
sobre.html: explicação sobre sustentabilidade.
galeria.html: imagens relacionadas à natureza e ao meio ambiente.
curiosidades.html: curiosidades e dicas para preservar o planeta.
Divisão de tarefas
[Saul felipe araujo dantas]: desenvolvimento das quatro páginas HTML, CSS e README.

O Flexbox foi utilizado:

Menu de navegação: foi utilizado display: flex, justify-content, align-items, gap e flex-wrap para organizar os links.
Galeria de imagens: foi utilizado display: flex, justify-content, align-items, gap e flex-wrap para organizar os cartões.

Também foi utilizada a propriedade flex-direction para adaptar a galeria em telas menores.
